This page has a title, an introduction and a few lines of plain text that are meant to be a table. At the moment, the browser runs them together. Over the next eleven steps you will build the table, one layer at a time.

Begin with the heading row. A row is a `tr`, and each heading is a `th`:

```html
<table>
  <tr>
    <th>Walk</th>
    <th>Length</th>
  </tr>
</table>
```

## Task

Replace the line `Walk, Length, Time, Difficulty` with a table that has one row of four `th` cells: `Walk`, `Length`, `Time` and `Difficulty`.

## Hints

- One `table`, one `tr`, four `th` elements.
- Do not keep the commas.
