A list item can hold more than plain text. In the route, the bridge has its own page, so make those words a link, inside the same `li`:

```html
<li>Cross the <a href="bridge.html">wooden bridge</a></li>
```

## Task

In the last step of the route, make `wooden bridge` a link to `bridge.html`.

## Hints

- The link goes inside the `li`, around only the two words.
- The item is still one `li`.
