The glossary pairs each word with its meaning, so it is a description list. The word goes in a `dt`, and the meaning goes in a `dd`. The colon is not needed any more:

```html
<dl>
  <dt>Switchback</dt>
  <dd>A sharp turn that helps a path climb.</dd>
</dl>
```
