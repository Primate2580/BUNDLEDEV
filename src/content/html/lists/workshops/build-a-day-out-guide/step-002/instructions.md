The route is a set of directions, and the order matters, because you cannot cross the bridge before you park. That makes it an ordered list. You do not type the numbers, because the browser adds them:

```html
<ol>
  <li>Park at the old mill</li>
  <li>...</li>
</ol>
```

## Task

Turn the three lines under `The route` into an ordered list with three items.

- Use `ol` this time, and no numbers in the text.
- One `li` for each line.
