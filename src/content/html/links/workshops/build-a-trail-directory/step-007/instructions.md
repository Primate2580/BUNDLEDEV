Long pages need a way back to the start. Give the top heading an id, and the closing line a link to it:

```html
<h1 id="top">Trail directory</h1>
<a href="#top">Back to the top</a>
```

## Task

Give the `h1` the id `top`, and turn `Back to the top` in the last paragraph into a link to `#top`.

## Hints

- The id goes on the `h1`.
- Wrap only the words `Back to the top`, and leave the full stop outside the link.
