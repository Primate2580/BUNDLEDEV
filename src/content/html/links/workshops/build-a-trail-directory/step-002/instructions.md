The Mill Creek walk lives in a folder called `walks`. A path that goes down into a folder starts with the folder's name and a slash, so the link needs the folder as well as the file name:

```html
<a href="walks/mill-creek.html">Mill Creek walk</a>
```

## Task

Turn `Mill Creek walk` into a link to `walks/mill-creek.html`.

## Hints

- The folder name and a slash come before the file name.
- File names use hyphens, never spaces.
