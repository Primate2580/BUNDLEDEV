A phone number can be a link too, using the `tel:` scheme. Write the number in international form, with a plus sign, the country code and no spaces, and keep the readable version as the link text:

```html
<a href="tel:+15550142">555 0142</a>
```

## Task

Turn `555 0142` into a link to `tel:+15550142`.

## Hints

- The `href` has no spaces in the number.
- The visible text keeps its space.
