Next, the Contact section. An email link uses the `mailto:` scheme before the address:

```html
<a href="mailto:rangers@example.com">rangers@example.com</a>
```

Without `mailto:`, the browser would treat the address as a file name.

## Task

Turn the address `rangers@example.com` into a `mailto:` link.

## Hints

- Put `mailto:` before the address inside the `href`.
- The link text stays as the plain address, so people can copy it.
