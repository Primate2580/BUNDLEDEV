With the ids in place, the welcome paragraph can link to them. A link to an id on the same page starts with a hash sign:

```html
<a href="#trails">Trails</a>
```

## Task

In the welcome paragraph, turn `Trails`, `Contact` and `Downloads` into three links to `#trails`, `#contact` and `#downloads`.

## Hints

- Three separate `a` elements, each wrapping one word.
- The hash goes in the link, and not in the id.
