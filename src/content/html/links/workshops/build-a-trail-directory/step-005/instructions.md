Now links within the page. First, each section needs a name that a link can point at. That name is an `id`, and it is written without a hash sign:

```html
<h2 id="trails">Trails</h2>
```

## Task

Give the three `h2` headings the ids `trails`, `contact` and `downloads`.

## Hints

- Put `id="..."` inside each opening `h2` tag.
- Use lowercase, because ids are case sensitive.
