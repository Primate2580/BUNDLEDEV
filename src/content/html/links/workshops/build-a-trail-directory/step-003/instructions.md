The weather forecast lives on a different website, so it needs an absolute URL, with the scheme and the host:

```html
<a href="https://example.com/forecast">weather service site</a>
```

## Task

## Hints

- An absolute URL starts with `https://`.
- Wrap only the words `weather service site`.
