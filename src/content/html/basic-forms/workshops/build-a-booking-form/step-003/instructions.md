The email field is almost the same, with one difference: its type is `email`. The browser then offers a better keyboard, and checks for an at sign:

```html
<input type="email" id="email" name="email">
```

## Task

Replace the plain word `Email` with a `p` that holds a labelled `email` input, with the id and name `email`.

## Hints

- Follow the pattern of the name field.
- The `type` is `email`.
