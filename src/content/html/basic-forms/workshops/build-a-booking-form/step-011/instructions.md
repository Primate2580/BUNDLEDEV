Two small hints help visitors. A `placeholder` shows an example of the format, and `rows` sets how tall the notes box starts. A placeholder never replaces the label, and it only gives a sample:

```html
<input type="email" ... placeholder="you@example.com">
<textarea ... rows="4"></textarea>
```

## Task

Add `placeholder="you@example.com"` to the email input, and `rows="4"` to the textarea.

## Hints

- Both go inside the opening tags.
- The labels stay where they are.
