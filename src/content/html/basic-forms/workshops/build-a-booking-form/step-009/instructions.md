Let the browser fill in what it already knows. The `autocomplete` attribute names what a field is for, using a fixed set of words, such as `name` and `email`:

```html
<input type="email" id="email" name="email" autocomplete="email">
```

## Task

Add `autocomplete="name"` to the name input and `autocomplete="email"` to the email input.

## Hints

- One more attribute on each of the two inputs.
- The values are the words `name` and `email`.
