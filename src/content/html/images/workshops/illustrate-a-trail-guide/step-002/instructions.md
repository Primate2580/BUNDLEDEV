Give the picture its size, so the browser can reserve room before the file arrives and nothing jumps. The file is 800 pixels wide and 450 tall:

```html
width="800" height="450"
```

## Task

Add `width="800"` and `height="450"` to the main picture.

## Hints

- The numbers are pixels, with no unit.
- Both attributes go inside the `img` tag.
