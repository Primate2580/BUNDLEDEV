A thin divider line between sections is decoration. It carries no information, so it gets an empty alt, and a screen reader skips it:

```html
<img src="images/divider.png" alt="">
```

## Task

Add an `img` for `images/divider.png` between the bridge paragraph and the `Gallery` heading, with an empty `alt`.

## Hints

- The attribute must be present, with an empty value.
- Do not describe it.
