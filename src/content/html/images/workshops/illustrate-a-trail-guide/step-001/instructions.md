This is a walk guide with its words in place, and no pictures yet. The files are meant to live in a folder called `images` next to the page, so the paths start with `images/`. The files do not exist in the Playground, so each picture will show its alt text instead of a photo, which is a useful preview of what a screen reader says.

Start with the main picture, right under the title. Describe what it shows, in your own words:

```html
<img src="images/mill-creek.jpg" alt="Mill Creek running between mossy banks">
```

## Task

Add an `img` for `images/mill-creek.jpg` between the title and the introduction, with a description in `alt`.

## Hints

- The alt should say what the picture shows, and must not be empty.
