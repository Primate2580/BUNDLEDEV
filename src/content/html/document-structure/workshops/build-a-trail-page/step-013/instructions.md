Images use the `img` element, a void element with a `src` (where the file is) and an `alt` attribute. `alt` is a short text description. Screen readers read it aloud, and browsers show it when the image can't load.

There is no `lake.jpg` in this project, so you'll see your alt text instead of a picture. That is exactly the fallback `alt` exists for.

## Task

After the lake paragraph, add an `<img>` with `src="lake.jpg"` and a meaningful `alt` description.

## Hints

- `img` is a void element, so it has no closing tag: `<img ... />`.
- Describe what the picture would show, for example `alt="Calm lake surrounded by pine trees"`.
