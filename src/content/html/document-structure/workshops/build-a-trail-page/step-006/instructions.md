Everything visitors see goes inside the `body` element, which comes after the `head`. A page should have one main heading, the `h1`, that says what the page is about.

Headings aren't just big text. They give the page an outline that screen reader users and search engines depend on.

## Task

After the closing `</head>` tag, add a `<body>` element containing an `<h1>` that says `Trail Guide`.

## Hints

- Put `<body>` after `</head>` and close it with `</body>` before `</html>`.
- Inside the body, write `<h1>Trail Guide</h1>`.
