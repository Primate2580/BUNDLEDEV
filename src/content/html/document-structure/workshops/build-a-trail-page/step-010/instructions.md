Links are what make the web a web. The `a` (anchor) element wraps the text you click, and its `href` attribute says where the link goes.

A link whose `href` starts with `#` jumps to the element on the same page that has that id. You'll create that destination in a moment.

## Task

Wrap the text of the first list item, `Lake loop`, in an `<a>` element whose `href` is `#lakes`.

## Hints

- The `a` goes inside the `li`, around the text: `<li><a ...>Lake loop</a></li>`.
- The opening tag is `<a href="#lakes">`.
