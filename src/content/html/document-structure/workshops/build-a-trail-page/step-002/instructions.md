The `html` element is the root of the page: everything else lives inside it. It should say which language the page is written in, using the `lang` attribute.

Screen readers use `lang` to choose the right pronunciation, and browsers use it for translation and hyphenation. It costs six characters and helps real people.

## Task

Add `lang="en"` to the opening `<html>` tag.

## Hints

- Attributes go inside the opening tag, after the element name: `<html lang="...">`.
- `en` is the code for English.
