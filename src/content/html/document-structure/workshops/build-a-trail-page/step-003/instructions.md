Inside `html` come two children. The first is `head`, which holds information about the page rather than content people read.

The most important item in the head is the **character encoding**. It tells the browser how to read the letters, accents and symbols in your file. Without it, text can turn into garbled characters. The tag is `meta` with a `charset` attribute, and because `meta` is a void element it has no closing tag.

## Task

Inside `<html>`, add a `<head>` element that contains `<meta charset="UTF-8" />`.

## Hints

- The head goes between `<html lang="en">` and `</html>`. Put the `meta` tag between `<head>` and `</head>`.
- Write the tag as `<meta charset="UTF-8" />`.
