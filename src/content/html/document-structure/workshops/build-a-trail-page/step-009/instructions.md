When items belong together, use a list. An unordered list is a `ul` whose children are `li` (list item) elements, and the browser adds the bullets for you.

Only `li` elements should sit directly inside a `ul`. Anything else belongs inside an `li`.

## Task

Below the `h2`, add a `<ul>` with three `<li>` items: `Lake loop`, `Pine ridge` and `Summit trail`.
