Every HTML page starts with a **doctype**, a short line that tells the browser to use modern standards. Without it, the browser switches to "quirks mode" and renders the page the old, inconsistent way that early websites relied on.

The doctype is not an element, so it has no closing tag. It goes at the very top of the file, before everything else.

## Task

Add `<!doctype html>` as the first line of the page.

## Hints

- It goes on its own line, above the `<html>` line.
- Type exactly `<!doctype html>`. Capital letters don't matter, but lowercase is the convention.
