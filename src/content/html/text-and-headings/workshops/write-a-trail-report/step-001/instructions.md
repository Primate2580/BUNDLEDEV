Here is a trail report, written as plain text. The words are all there, but the browser has no idea which line is a title, which is a paragraph and which is a quote, so it runs everything together. Over the next thirteen steps you will tell it what each piece is, and the page will take shape.

Start with the title. The first line is the name of the whole page, so it is a level 1 heading:

```html
<h1>Ridge Trail report</h1>
```

## Task
