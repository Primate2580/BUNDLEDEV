Stagger the cards, so a sweep of the pointer across the row ripples. A delay is a wait before the journey, and it belongs on each card's own rule, so you need one rule per position.

Because the delays are on the base rule, they apply on the way back too, and the ripple repeats in the same order. Keep them tiny, or the cards feel unresponsive. Hover, pressed and checked states cannot be read by the automatic checks, so they look at the base styles. Try the state in the preview to see the rule work.
