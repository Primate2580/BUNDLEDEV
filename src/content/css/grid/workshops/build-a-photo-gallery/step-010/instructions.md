`gap` can take two values: the **row gap** first, then the **column gap**. This tightens the vertical spacing to `8px` while keeping `16px` between columns.

It is a shorthand for `row-gap` and `column-gap`, and the order (rows first, then columns) is easy to remember because it matches how you read a table from top to bottom, then left to right.
