The numbers sit in the top-left corner of each tile. Grids nest just like flexbox containers: each tile can be a grid container for its own contents.

`justify-items` positions content horizontally inside a cell, and `align-items` positions it vertically. With a single item, `center` for both puts the label exactly in the middle.

## Task

Add `display: grid;`, `justify-items: center;` and `align-items: center;` to the `.tile` rule.

- Together they centre each tile's label in both directions.
