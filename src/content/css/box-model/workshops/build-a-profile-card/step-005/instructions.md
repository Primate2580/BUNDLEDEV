**Margin** is the space *outside* the border, and it pushes other things away. It is transparent, so the grey page shows through.

`margin: 32px auto` is two values: `32px` for top and bottom, and `auto` for left and right. On a block with a set width, `auto` splits the leftover side space equally, which centres the card.

## Task

Add `margin: 32px auto;` to `.card`.

## Hints

- Two values mean: top and bottom first, then left and right.
- Write `margin: 32px auto;` inside `.card`.
