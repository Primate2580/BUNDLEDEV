The border is the line drawn around the padding. The `border` shorthand takes three values in any order: a **width**, a **style** (such as `solid` or `dashed`) and a **colour**.

Without a style, no border appears at all, even if you set a width. That is the most common reason a border seems to be missing.

## Task

Add `border: 2px solid #cbd5e1;` to `.card`.
