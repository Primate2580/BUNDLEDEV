Square corners can feel harsh. `border-radius` rounds the corners of the box. It rounds the border and the background together, so the white fill follows the curve.

A larger value gives a rounder corner, and a value of half the box's height gives a pill shape.

Add `border-radius: 16px;` to `.card`.
