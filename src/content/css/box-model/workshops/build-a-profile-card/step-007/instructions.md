Headings and paragraphs come with default margins from the browser, which is why there is a big gap above the name. The browser's default stylesheet adds them, and you can override them.

`margin: 0 0 4px` is three values: top `0`, left and right `0`, bottom `4px`. It pulls the name flush to the top and leaves a small gap before the role.

## Task

Add a `.name` rule with `margin: 0 0 4px;`.

## Hints

- Create a new rule with the selector `.name`.
- `.name { margin: 0 0 4px; }`.
