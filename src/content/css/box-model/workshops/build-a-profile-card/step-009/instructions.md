The button is a link, which is an **inline** element. Inline elements flow like words in a sentence, and their vertical padding is drawn but doesn't push other content away, so the button looks cramped.

`display: inline-block` keeps it sitting in the line like a word, but lets it have a proper box: width, height, and padding that really takes up space.

## Task

Add `display: inline-block;` and `padding: 10px 20px;` to `.button`.

## Hints

- Both lines go in the existing `.button` rule.
- `display: inline-block;` then `padding: 10px 20px;`.
