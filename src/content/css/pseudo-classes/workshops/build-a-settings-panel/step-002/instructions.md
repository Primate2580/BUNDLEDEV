Stripe every other row, so the eye can follow across a wide row. `:nth-child(even)` selects the 2nd, 4th, 6th, and so on, and a very pale background is enough.

Because it is based on position, the stripes stay correct if the order of the settings changes.

## Task

Add a new rule `.setting:nth-child(even)` with `background-color: #f8fafc;`.

## Hints

- A new rule, with one declaration.
- `.setting:nth-child(even) { background-color: #f8fafc; }`
