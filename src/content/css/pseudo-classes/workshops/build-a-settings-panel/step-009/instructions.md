Pseudo-elements add decoration without adding HTML. A small round "?" before the help text is generated by `::before`. Because the paragraph is a flex container, the pseudo-element becomes a flex item, and `gap` spaces it from the text, with no margin needed. Hover, focus and generated content cannot be checked automatically, so the checks look at the base styles. Hover over the preview, or use DevTools' `:hov` panel, to see the state rule work.

A pseudo-element needs `content`, and it is inline by default, so give it `display: inline-flex`, a size and a radius to make a circle.

## Task

Add `display: flex;`, `align-items: center;` and `gap: 0.5rem;` to the `.help` rule. Then add a new rule `.help::before` with `content: "?";`, `display: inline-flex;`, `align-items: center;`, `justify-content: center;`, `width: 1.25rem;`, `height: 1.25rem;`, `border-radius: 50%;`, `background-color: #e0e7ff;`, `color: #3730a3;`, `font-size: 0.8125rem;` and `font-weight: 700;`.
