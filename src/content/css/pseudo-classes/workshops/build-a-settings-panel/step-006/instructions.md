The Save button is disabled until the form is ready. Give `:disabled` buttons a flat grey look and a cursor that says "not available". Without the cursor, it can feel as though the page is broken.

The rule is for **disabled** buttons only, so enabled buttons keep their indigo colour from the base rule.

## Task

Add a new rule `.save:disabled` with `background-color: #94a3b8;` and `cursor: not-allowed;`.

## Hints

- Two declarations in a new rule.
- `.save:disabled { background-color: #94a3b8; cursor: not-allowed; }`
