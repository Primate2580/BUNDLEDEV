`display: none` removes an element from the page completely. It isn't drawn, it takes up no space, and assistive technology ignores it too. It is the right way to hide something that should truly be gone.

Hiding the note is a clean example: the menu above it doesn't move, and nothing is left behind.

## Task

Add a `.note` rule with `display: none;`.

## Hints

- Use the class selector `.note`.
- `.note { display: none; }`.
