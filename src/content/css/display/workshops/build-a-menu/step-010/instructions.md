The finishing touch is the difference between `flex` and `inline-flex`. A `flex` container is **block-level**: it stretches across the full width. An `inline-flex` container sits in a line like a word, and only grows as wide as its items.

Switch the list to `inline-flex` and its box shrinks to fit the four links.

## Task
