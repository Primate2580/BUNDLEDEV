The last link is the current page. Its element has two classes, `link` and `current`, and `.link.current` (no space) selects an element with both.

A box that has real padding can carry a visible background, which makes it a good way to mark the current item.

## Task

Add a `.link.current` rule with `font-weight: 700;`, `background-color: #e0e7ff;` and `border-radius: 8px;`.

## Hints

- No space between the two class names: `.link.current`.
- Three declarations: bold, a light indigo background, and rounded corners.
