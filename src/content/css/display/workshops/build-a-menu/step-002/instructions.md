The row has bullets and an indent. Those come from the browser's default styles for `ul`: a marker for each item, and left padding to make room for it.

Removing them is a reset. `list-style-type: none` removes the markers, and zero padding and margin remove the indent and the outer spacing.

## Task

Add a rule for `.menu-list` that sets `list-style-type: none;`, `padding: 0;` and `margin: 0;`.

## Hints

- Three declarations in one `.menu-list` rule.
- `list-style-type: none;`, `padding: 0;`, `margin: 0;`.
