The button needs size and room. Give it a `rem` font size, and then use `em` for the padding, so the button's spacing scales with its own text. If someone makes the button bigger later, the padding follows automatically.

`0.75em 1.5em` means three quarters of the button's own font size above and below, and one and a half times at the sides. At 16px, that is 12px and 24px.

## Task

Add `font-size: 1rem;` and `padding: 0.75em 1.5em;` to the `.btn` rule.

## Hints

- Both go in the `.btn` rule.
- `font-size: 1rem; padding: 0.75em 1.5em;`
