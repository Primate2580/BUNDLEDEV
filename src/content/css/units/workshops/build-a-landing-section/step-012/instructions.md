Here is the payoff for using `rem` everywhere. Every font size, padding, gap and maximum width in this page is measured from the root font size, so changing that one number scales the whole design.

Set the root to `112.5%`, which is 18px at the default, and watch everything grow together. A percentage keeps the user's own setting in charge, because 112.5% of their default is still based on it.
