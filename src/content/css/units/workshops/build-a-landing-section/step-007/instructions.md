Now the feature cards. The row of cards needs space between them and around the section. The `gap` property sets the space between flex items, and padding adds space inside the section. Both use `rem`.

Spacing between sections and elements is a good job for `rem`: it grows with the user's text size, and it never compounds the way `em` can.
