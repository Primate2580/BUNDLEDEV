Each card needs padding and rounded corners. Padding in `rem` gives every card the same comfortable space, and a `rem` radius keeps the corners proportional to the page's text size.

Compare this with the button: the button's spacing belongs to its own text, so it used `em`. A card's spacing belongs to the page layout, so it uses `rem`.

## Task

Add `padding: 1.5rem;` and `border-radius: 0.75rem;` to the `.feature` rule.
