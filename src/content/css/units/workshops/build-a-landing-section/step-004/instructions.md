Now the hero's text. The title gets a bigger size in `rem`. The paragraph is limited to about 36 characters per line with `ch`, the width of a zero in the current font, which keeps short intro text neat.

`ch` follows the font, so `36ch` still holds roughly the same number of characters if you later change the text size.

## Task

Add `font-size: 2.5rem;` to `.hero-title` and `max-width: 36ch;` to `.hero-text`.

## Hints

- Two rules, one declaration each.
- `.hero-title { font-size: 2.5rem; }` and `.hero-text { max-width: 36ch; }`
