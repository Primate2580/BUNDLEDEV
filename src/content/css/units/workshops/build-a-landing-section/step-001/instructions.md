The page uses the browser's default 16px text and tight lines. Start with the foundation: a slightly larger body size in `rem`, and a unitless line height.

`1.125rem` is 18px at the default root size, and it follows anyone who has changed their default. The line height `1.6` has no unit, so every element multiplies it by its own font size.

## Task

Add `font-size: 1.125rem;` and `line-height: 1.6;` to the `body` rule.

## Hints

- Both go in the `body` rule.
- `font-size: 1.125rem; line-height: 1.6;`
