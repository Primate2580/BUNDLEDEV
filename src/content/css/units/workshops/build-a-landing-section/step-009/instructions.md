The cards wrap onto new rows when the screen is narrow, but each can shrink without limit. A minimum width in `rem` gives each card a sensible size to wrap around.

`14rem` is 224px at the default size, and it grows if the user's text does, so the card is always wide enough for its text.

## Task

Add `min-width: 14rem;` to the `.feature` rule.
