Look closely at the button: it is taller than the plain links, so the items don't line up on their baseline. Positioning items **across** the main axis is the job of `align-items`.

The default is `stretch`, which makes every item as tall as the tallest one. `center` instead centres each item vertically in the header.

## Task

Add `align-items: center;` to `.site-header`.

## Hints

- The cross axis is vertical when the main axis is horizontal.
