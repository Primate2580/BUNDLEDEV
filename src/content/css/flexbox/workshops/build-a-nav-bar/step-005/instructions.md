The links are now in a row, but touching. You could add margins to each link, but there is a better tool: **`gap`**, which puts space *between* items without touching the items themselves.

Because the gap belongs to the container, there is no extra space after the last link, and you can change the spacing in one place.

## Task

Add `gap: 24px;` to the `.nav` rule.
