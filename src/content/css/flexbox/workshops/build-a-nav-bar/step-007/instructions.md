When the window gets narrow, flex items **shrink** to fit, and the button could get squashed and wrap its text. `flex-shrink` controls how willing an item is to shrink.

Its default is `1` (shrink if needed). Setting it to `0` says: this item keeps its own size, so the others have to give way.

## Task

Add `flex-shrink: 0;` to the `.cta` rule.

## Hints

- Find the `.cta` rule near the bottom.
- Add `flex-shrink: 0;` inside it.
