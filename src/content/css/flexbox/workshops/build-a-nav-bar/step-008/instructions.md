By default a flex container keeps everything on **one line**, squeezing items if it has to. On a small screen that can be worse than letting items move down.

`flex-wrap: wrap` lets items that run out of room continue on a new line, so the header stays readable at any width.

## Task

Add `flex-wrap: wrap;` to `.site-header`.
