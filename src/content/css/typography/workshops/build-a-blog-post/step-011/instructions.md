Code in the tip should look like code: a monospace font, which gives every letter the same width. List a few common monospace fonts, ending with the generic `monospace`.

The size is in `em`, which on `font-size` is relative to the parent. `0.9em` makes the code a touch smaller than the sentence around it, because monospace fonts often look larger than body fonts at the same size.

## Task

Add `font-family: ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace;` and `font-size: 0.9em;` to a new `.code` rule.

## Hints

- Create a new rule: `.code { ... }`.
- `.code { font-family: ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace; font-size: 0.9em; }`
