The lines sit close together. A unitless `line-height` of `1.6` gives each line 1.6 times its own font size, which is comfortable for reading paragraphs.

Because it has no unit, the number is inherited as a number. Headings, which have bigger text, will work out their own line height from it, and you can tighten them later.
