Why body text should be bigger than you think

By Ada Okafor · 6 min read

Most pages set text too small, too tight and too wide. Three small changes fix all of it.

Size comes first

Browsers start at 16px for a reason: it is a comfortable size on almost every screen. Going smaller to look refined usually just makes people squint.

Setting the size in rem means the page also respects anyone who has raised their default text size, which is exactly the person who needs it most.

Readers should never have to think about the text itself.

Space does the rest

Generous line height and a narrow column let the eye travel from one line to the next without effort. Most of that comes from two numbers.

Try line-height: 1.6 on the body and see how the page changes.
