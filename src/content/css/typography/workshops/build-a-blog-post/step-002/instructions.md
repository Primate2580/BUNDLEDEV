The browser default is 16px. For a long read, a little bigger is kinder, and `1.125rem` is 18px at the default size. Because it is in `rem`, it also grows if the reader has raised their own default.

Set the size once on `body`. Everything inherits it, except the elements that have their own size, such as headings, which you will style shortly.

## Task

Add `font-size: 1.125rem;` to the `body` rule.
