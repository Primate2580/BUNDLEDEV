Finally, a preview of a focus ring. Keyboard users need to see which control has focus, and an outline is the right tool, because it takes no space and survives high-contrast modes. `outline-offset` moves it a little away from the button.

In a real stylesheet, you would put these inside `.buy:focus-visible`, so the ring appears only when needed. Here they are on the button itself, so you can see the effect.
