An inset shadow is drawn inside the box. A hard, zero-blur shadow along the bottom edge makes a solid darker ledge, which makes the button feel like a physical key.

`inset 0 -2px 0 rgb(0 0 0 / 0.25)` draws a 2px dark line along the bottom inside edge. The negative y offset moves the shadow up from the bottom, and `inset` keeps it inside.
