The route cards come next. On a phone, they should stack in one column. A grid with a `gap` and some padding gives you exactly that, because a grid with no columns defined simply has one.

You do not need a media query for the one-column layout. It is the default.

## Task

Add `display: grid;`, `gap: 1rem;` and `padding: 1rem;` to the `.routes` rule.

## Hints

- Three declarations in `.routes`.
- `display: grid; gap: 1rem; padding: 1rem;`
