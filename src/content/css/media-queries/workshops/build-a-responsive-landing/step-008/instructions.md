The call-to-action button must be easy to tap. The commonly recommended minimum is 44 by 44 pixels, which is `2.75rem`. A flex box inside the button centres its text vertically, and `rem` padding at the sides gives it a comfortable width.

A button this size works on every device, so it does not need a media query.

## Task

Add `display: inline-flex;`, `align-items: center;`, `min-height: 2.75rem;` and `padding: 0 1.25rem;` to the `.btn` rule.

## Hints

- Four declarations in `.btn`.
- `display: inline-flex; align-items: center; min-height: 2.75rem; padding: 0 1.25rem;`
