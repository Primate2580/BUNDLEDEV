Not every colour needs a numeric code. For the feature list we will use a named colour. `darkslategray` is a dark grey-green that reads clearly on white, about 8.9:1.

Named colours are quick and readable, but you only get the ones on the list, so they are best for sketches and for neutral colours like this one.

## Task

Add `color: darkslategray;` to the `.features` rule.

## Hints

- Names are written without quotes.
- `color: darkslategray;`
