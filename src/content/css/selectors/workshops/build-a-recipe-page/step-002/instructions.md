Type selectors are broad. To style one particular paragraph, give it a label in the HTML with the `class` attribute and then select it with a **class selector**: a dot followed by the class name.

Look at the html tab: the first paragraph has `class="intro"`. The selector `.intro` matches every element that has that class, and only those.

## Task

Add a rule with the selector `.intro` and `font-style: italic;`.

## Hints

- A class selector starts with a dot: `.intro`.
- `.intro { font-style: italic; }`.
