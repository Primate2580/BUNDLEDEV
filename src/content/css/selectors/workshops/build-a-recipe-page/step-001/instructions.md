A CSS rule has two halves: a **selector** that picks elements, and a **declaration block** that styles them. The simplest selector is a **type selector**, which is just the name of an HTML element. It matches every element of that type.

`h1` matches every `h1` on the page, so this one rule restyles all of them.

## Task

Add a rule with the selector `h1` and the declaration `color: #1e1b4b;`.

## Hints

- Write the element name, then curly braces: `h1 { ... }`.
- Inside the braces: `color: #1e1b4b;`.
