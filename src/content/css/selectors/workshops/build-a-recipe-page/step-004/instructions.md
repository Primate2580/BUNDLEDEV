Classes can be shared by many elements. Each of the three list items has `class="ingredient"`, so one class selector styles all three.

`list-style-type` changes the marker in front of a list item. `square` swaps the round bullets for squares.

## Task

Add a rule for `.ingredient` with `list-style-type: square;`.

## Hints

- The selector is `.ingredient`.
- `.ingredient { list-style-type: square; }`.
