Back to a type selector, to see how it behaves with several matches. There are two `h2` headings in the recipe, and one rule styles both.

This is the trade-off: a type selector is quick, but it has no way to pick just one of them. Classes are for when you need to be selective.

## Task

Add a rule that makes every `h2` the colour `#4338ca`.
