The same corner radius is on the card and on the button. One token will keep them in step, so a designer who asks for squarer corners needs to change one number, not hunt for two.

## Task

Add this token to `:root`:

```css
--radius: 0.75rem;
```

Then set `border-radius` to `var(--radius)` in both the `.card` rule and the `.btn` rule.

## Hints

- One new line, and two values replaced.
- The page looks the same.
