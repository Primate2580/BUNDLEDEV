HOW TO APPLY (Windows, PowerShell, from the folder that contains css-lab-main)
  1. Extract this zip INTO css-lab-main and choose "Replace the files in the destination".
  2. cd css-lab-main
  3. npm run build:content
  4. npm run typecheck
  5. npm run test:content
  6. npm run dev   (open Cascade and specificity under CSS > Advanced)

THE TOPIC (22 lessons)

DESIGN NOTE
  jsdom applies "last rule wins" and ignores specificity and !important, so every auto-checked
  case is built so the real winner and the "last rule" agree: the heavier rule is written
  later in each solution. Pure specificity questions (specific rule written first) live in the
  predict lessons without auto-checks.
